## Тема и идея работы

Цель лабораторной работы - создать простое оконное приложение на Python и освоить работу с элементами интерфейса.

В программе показано окно с кнопкой. После нажатия кнопки текстовая область заменяется изображением. Дополнительно реализованы смена кнопки и возврат к начальному состоянию: появляется кнопка «Хочу назад», а после её нажатия снова отображается исходная кнопка.

## Описание программы

Основной класс `MainWindow` создаёт главное окно. В нём размещены область для текста или изображения и две кнопки:

- «Тыкни на меня» - показывает изображение;
- «Хочу назад» - возвращает первоначальный экран.

Кнопка возврата при запуске скрыта. Нажатие первой кнопки вызывает метод `show_picture`: программа загружает файл `picture.jpg`, показывает его в окне, скрывает первую кнопку и отображает кнопку возврата.

```python
self.button.clicked.connect(self.show_picture)
self.back_button.clicked.connect(self.show_start_screen)
```

Этот фрагмент связывает нажатия кнопок с действиями программы.

При возврате метод `show_start_screen` очищает область изображения, скрывает кнопку «Хочу назад» и снова показывает исходную кнопку.

```python
self.label.clear()
self.back_button.hide()
self.button.show()
```
