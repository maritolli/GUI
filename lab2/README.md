## Тема и идея работы

Тема лабораторной работы - сигналы и слоты в PyQt5.

В работе создан конвертер валют с полями для рублей, долларов и евро. Пользователь может изменить значение в любом поле, после чего два остальных поля пересчитываются автоматически. Это показывает принцип сигналов и слотов: изменение значения в элементе интерфейса вызывает нужный метод программы.

Дополнительно реализована загрузка официальных курсов доллара и евро с сайта Центрального банка России по выбранной дате. Если загрузка невозможна, например из-за отсутствия интернета или неожиданного ответа сервера, программа использует заранее подготовленные (моковые) значения курсов. Поэтому конвертер остаётся работоспособным в непредвиденной ситуации.

## Описание программы

Главное окно создаётся классом `CurrencyConverter`. В нём расположены:

- поле выбора даты;
- кнопка загрузки курса;
- поля ввода суммы в рублях, долларах и евро;
- строка с текущими курсами и источником данных.

Каждое поле суммы отправляет сигнал при изменении своего значения. Этот сигнал соединён с методом, который пересчитывает остальные значения.

```python
self.rubles.valueChanged.connect(self.update_from_rubles)
self.dollars.valueChanged.connect(self.update_from_dollars)
self.euros.valueChanged.connect(self.update_from_euros)
```

Например, если пользователь меняет количество долларов, вызывается `update_from_dollars`. Метод вычисляет сумму в рублях и евро, затем выводит результаты в соответствующие поля.

```python
def update_from_dollars(self, dollars):
    rubles = dollars * self.rub_per_usd
    euros = dollars * self.eur_per_usd
    self.set_values(rubles, dollars, euros)
```

При программном обновлении полей их сигналы временно блокируются. Это предотвращает повторные срабатывания и зацикливание пересчёта.

```python
blockers = (
    QSignalBlocker(self.rubles),
    QSignalBlocker(self.dollars),
    QSignalBlocker(self.euros),
)
```

По кнопке «Загрузить курс» программа запрашивает XML-данные ЦБ РФ, находит курсы USD и EUR и применяет их к текущей сумме. Если получить или обработать данные не удалось, вызывается метод `use_default_rates`, который подставляет моковые курсы. В результате пользователь видит понятное сообщение, а приложение продолжает работать.
